## Known Issues & Notes
- Memory Match mismatch unlock & Number Battle AI stalls resolved in previous update.
- Phase 1 Architecture complete: 44 original games cataloged, 7 categories + Featured, multi-filter & sorting, responsive Poki-style cards, and upgraded game details modal with desktop/mobile controls guide and local high scores.
- Phase 2 Core Games refined:
  - Tic-Tac-Toe: Minimax AI (Easy/Medium/Hard), win detection, win line highlighting, score, rematch.
  - Connect 4: Alpha-Beta AI (Easy/Medium/Hard), drop physics, win highlight, rematch.
  - Rock Paper Scissors: Added series format selection (Best of 3 vs Best of 5), manual Next Round progression, and AI counter-strategy.
  - Memory Match: Added board size selection (3x4 Easy, 4x4 Medium, 4x5 Hard), live stopwatch timer, and mismatch flip resolution.
  - Reaction Rush: Real-time ms reaction timing, false-start penalty, 5-round scoreboard, and ranking.
- Next Phase: Phase 3 (Local Multiplayer Framework, Room Management, WebSockets, LAN/Hotspot synchronization).
